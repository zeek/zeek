Detailed Interface
~~~~~~~~~~~~~~~~~~
Types
#####
.. zeek:type:: DHCPv6::MessageInfo
   :source-code: base/protocols/dhcpv6/spicy-events.zeek 11 44

   :Type: :zeek:type:`record`


   .. zeek:field:: msg_type :zeek:type:`count`

      Message type, as defined in :rfc:`8415#section-7.3`.


   .. zeek:field:: transaction_id :zeek:type:`count`

      Transaction identifier tying the exchange together.


   .. zeek:field:: client_duid_type :zeek:type:`count` :zeek:attr:`&optional`

      DUID type of the client DUID option, if present.


   .. zeek:field:: client_duid :zeek:type:`string` :zeek:attr:`&optional`

      Raw client DUID bytes (following the type field).


   .. zeek:field:: server_duid_type :zeek:type:`count` :zeek:attr:`&optional`

      DUID type of the server DUID option, if present.


   .. zeek:field:: server_duid :zeek:type:`string` :zeek:attr:`&optional`

      Raw server DUID bytes (following the type field).


   .. zeek:field:: requested_options :zeek:type:`vector` of :zeek:type:`count` :zeek:attr:`&optional`

      Option codes requested via the ORO option.


   .. zeek:field:: iaid :zeek:type:`count` :zeek:attr:`&optional`

      IAID of the first IA_NA option seen.


   .. zeek:field:: t1 :zeek:type:`count` :zeek:attr:`&optional`

      Preferred lease renewal time (T1) for the IA.


   .. zeek:field:: t2 :zeek:type:`count` :zeek:attr:`&optional`

      Preferred lease rebinding time (T2) for the IA.


   .. zeek:field:: assigned_addr :zeek:type:`addr` :zeek:attr:`&optional`

      Address of the first IA Address option nested in an IA_NA.


   .. zeek:field:: preferred_lifetime :zeek:type:`count` :zeek:attr:`&optional`

      Preferred lifetime of the assigned address, in seconds.


   .. zeek:field:: valid_lifetime :zeek:type:`count` :zeek:attr:`&optional`

      Valid lifetime of the assigned address, in seconds.


   .. zeek:field:: status_code :zeek:type:`count` :zeek:attr:`&optional`

      Status code from the STATUS_CODE option.


   .. zeek:field:: status_message :zeek:type:`string` :zeek:attr:`&optional`

      Status message from the STATUS_CODE option.


   .. zeek:field:: client_fqdn :zeek:type:`string` :zeek:attr:`&optional`

      FQDN provided by the client via the CLIENT_FQDN option.


   A flat summary of a parsed DHCPv6 client/server message, populated by
   the analyzer for each non-relay message. Fields sourced from options
   that were not present in the message are left unset.

Events
######
.. zeek:id:: dhcpv6_message
   :source-code: base/protocols/dhcpv6/main.zeek 185 192

   :Type: :zeek:type:`event` (c: :zeek:type:`connection`, is_orig: :zeek:type:`bool`, msg: :zeek:type:`DHCPv6::MessageInfo`)

   Generated for each parsed DHCPv6 message.


   :param c: The connection.


   :param is_orig: Whether the message came from the originator.


   :param msg: Flat summary of the parsed message (see :zeek:type:`DHCPv6::MessageInfo`).
